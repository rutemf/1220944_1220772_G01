# Requirements - System To-Be

## Architecturally Significant Requirements (ASR)

- Persistence of relational and document data models, MySQL and MongoDB respectively, Database Management System (DBMS).
- ID Generation of the forms...
- Integration with the external systems Google Books API and Open Library Search API to retrieve books isbn's by title.
- Definition of the alternatives above during setup time, impacting directly the runtime behavior.

## Other Requirements

- Adoption of Attribute Driven Design (ADD)
